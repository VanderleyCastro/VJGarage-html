🏍️ Mi Primera Web - Tienda de Motos

Proyecto de una página web estática desarrollada con HTML y CSS, que simula el sitio web de una tienda de motocicletas.

El objetivo del proyecto es practicar estructuración de páginas web, navegación entre páginas y estilos con CSS.

🌐 Páginas del sitio

🏠 "index.html"

Página principal del sitio web donde se presenta la tienda y se accede al resto de secciones.

🏍️ "sport.html"

Muestra motocicletas deportivas.

🏔️ "adventure.html"

Sección dedicada a motocicletas de aventura.

🏁 "offroad.html"

Motocicletas diseñadas para terrenos difíciles o fuera de carretera.

🎯 "mision.html"

Describe la misión de la empresa.

🔭 "vision.html"

Describe la visión y objetivos de la empresa.

📞 "contacto.html"

Página donde los usuarios pueden ver información de contacto y enviar datos mediante un formulario.

---

🎨 Tecnologías utilizadas

- HTML5
- CSS3

El proyecto utiliza:

- Estructura semántica de HTML
- Estilos centralizados en "styles.css"
- Imágenes organizadas en una carpeta "pictures"

---

🎯 Objetivo del proyecto

Este proyecto fue desarrollado para:

- Practicar estructura de páginas web
- Aprender uso de CSS
- Implementar navegación entre múltiples páginas
- Organizar archivos e imágenes en un proyecto web
